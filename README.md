# Gran Canaria Establishments Visualizer (Three.js)

A web application built with **Three.js** that renders a textured map of the island of Gran Canaria and plots geolocated establishments from a CSV file, transforming real-world latitude and longitude coordinates into 3D spatial coordinates.

---

## Technologies & Libraries Used
- **[JavaScript (ES6+)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)**
- **[Three.js](https://threejs.org/)**

---

## Setup & run

1. **Clone or download** this repository to your local machine.

2. Open a terminal in the root folder of the project (`GranCanariaDensityMap`) and install dependencies:
   ```bash
   npm install
   
3. Execute and go to your localhost.
   ```bash
   nmp start
